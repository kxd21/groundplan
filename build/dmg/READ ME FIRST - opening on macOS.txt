OPENING GROUNDPLAN THE FIRST TIME
=================================

macOS will refuse to open Groundplan the first time, and will say something
like:

    "Apple could not verify 'Groundplan' is free of malware that may harm
     your Mac or compromise your privacy."

This is expected. It is not a warning about Groundplan specifically.

macOS shows that message for any application that has not been through
Apple's paid notarisation service. Groundplan is distributed without it, so
every copy shows it. You approve the app once, and it opens normally from
then on.


FIRST: INSTALL
--------------

  1. Drag Groundplan onto the Applications folder in this window.
  2. Eject this disk image.


THEN: APPROVE IT ONCE
---------------------

Apple changed how this works in macOS 15, so there are two routes.
Check your version with:  Apple menu > About This Mac


  If you are on macOS 15 (Sequoia), macOS 26 (Tahoe) or later
  -----------------------------------------------------------
  Control-clicking does NOT work on these versions. Use System Settings.

  1. Open Applications and double-click Groundplan.
  2. A dialog says it cannot be opened. Click Done.
  3. Open System Settings, then Privacy & Security.
  4. Scroll down to the Security section. It says:
         "Groundplan" was blocked to protect your Mac.
  5. Click Open Anyway.
  6. Authenticate with Touch ID or your password.
  7. One more dialog appears. Click Open Anyway again.

  Groundplan opens, and opens directly from then on.

  Note: that Security message only appears for about an hour after the app
  was blocked. If you do not see it, double-click Groundplan again and go
  straight back to Privacy & Security.


  If you are on macOS 14 (Sonoma) or earlier
  ------------------------------------------
  1. Open Applications.
  2. Control-click (or right-click) Groundplan.
  3. Choose Open.
  4. Click Open in the dialog.

  The Control-click is the part that matters: it turns the block into a
  choice. Double-clicking will only ever refuse.


IF IT SAYS "DAMAGED AND CAN'T BE OPENED"
----------------------------------------

macOS says this about a downloaded app whose quarantine flag it cannot
resolve, usually after the file has been moved between machines. Open
Terminal and run:

    xattr -dr com.apple.quarantine /Applications/Groundplan.app

Then open Groundplan normally.


WHY DOES THIS HAPPEN AT ALL?
----------------------------

Removing the prompt requires an Apple Developer Program membership and a
"Developer ID Application" certificate, which carries an annual fee. This
build is not enrolled, so the one-time approval above is the trade-off.

The application IS signed - ad-hoc, which is what allows it to run on Apple
silicon at all. It is simply not notarised by Apple.

Approving Groundplan does not turn off Gatekeeper or weaken anything else on
your Mac. The approval applies to this one application.
