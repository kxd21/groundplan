macOS

This computer
  1. Open the .dmg.
  2. Drag Groundplan onto Applications.
  3. Open Groundplan from Applications.
One-time approval: the first launch needs a short Privacy & Security approval because the public build is not Apple-notarized. Exact clicks are below.

Windows

This computer
  1. Run the Setup .exe.
  2. Choose Just me unless every account needs it.
  3. Launch Groundplan from the Start menu.
SmartScreen: choose More info, then Run anyway. The Portable download needs no admin access.

Linux

This computer
  1. Download the .AppImage.
  2. Make it executable with chmod +x.
  3. Open it from your file manager or terminal.
FUSE: some distributions need FUSE support for AppImages.

macOS 15 Sequoia, 26 Tahoe, and later

Use System Settings once.

  1. Open Groundplan once and click Done.
  2. Open System Settings → Privacy & Security.
  3. Under Security, click Open Anyway, authenticate, and confirm.

macOS 14 Sonoma and earlier

Use the Control-click route.

  1. Open the Applications folder.
  2. Control-click Groundplan and choose Open.
  3. Click Open once more.
