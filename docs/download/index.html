Install

macOS

  1. Open the .dmg and drag Groundplan into Applications.
  2. Eject the disk image, then open Groundplan from Applications.
First open on Mac. If Gatekeeper blocks it, right-click the app → Open → Open again. You only do this once. Builds are ad-hoc signed; Apple notarization is not applied yet.

Windows

  1. Run the Setup .exe.
  2. Choose Just me unless every account on the PC should have it.
  3. Launch from the Start menu.
SmartScreen. Click More info, then Run anyway. Prefer the portable build if you have no admin rights — put it anywhere you can write and run it.

Open a plan

File → Open and pick a .rv4 (or .rs4, .ds4, shape libraries). Existing Room Viewer files open as they are — Groundplan edits the original format.
